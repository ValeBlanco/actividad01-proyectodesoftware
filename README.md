Aclaracion: La carpeta llamada ludoteca_enunciado7 corresponde a la version del sitio web creada por la IA Gemini. La carpeta llamada juegosdemesa corresponde a la version hecha por Claude.

Como ejecutar el proyecto de la actividad 1:

-Paso 1: Clonar el repositorio. Se debe ejecutar git clone "URL del repositorio".

-Paso 2: Ejecutar en la terminal el comando: python3 -m http.server.

-PAso 3: Ingresar a la direccion: http://localhost:8000. Esta permitira elegir una de las dos versiones web para ingresar.
